# trucktap-web

The public TruckTap website — standalone, SEO-indexed truck profile pages and city/cuisine directories, genuinely useful without the app.

Built with [Next.js](https://nextjs.org) (App Router), TypeScript, and Tailwind CSS.

## Getting started

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it locally.

## Status

Foundation only. Not yet connected to Supabase, Vercel, Porkbun, or any live data source.
